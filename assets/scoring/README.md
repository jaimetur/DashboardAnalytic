# Local scoring reference

`netcheck_2026.json` is a local, Git-ignored reference in the importable Scoring Configuration format. The application does not load it automatically. Import it explicitly through Workspace Config or Admin to store its rules in a workspace database.

The workspace database is the authoritative source. Original Tableau, Excel, PDF and example PPT documents are reference material only.

See [Scoring methodology configuration](../../help/scoring-methodology.md) for the format, runtime behavior and future methodology updates.
