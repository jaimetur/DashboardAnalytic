# Contributing

> [!IMPORTANT]
> **Focused changes.** Keep the implementation, relevant tests and documentation aligned. Source code, UI text, comments and documentation use English.

1. Create a focused branch.
2. Run tests locally.
3. Open a pull request with a clear change summary.
4. Keep documentation and code comments in English.

See [Project Structure](help/project-structure.md) for source ownership and [Run from source](README.md#run-from-source) for local setup.
