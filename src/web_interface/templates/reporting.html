E2E PowerPoint Reporting

Choose a reporting module

Produce a consistent, template-based NetCheck CDR PowerPoint from one or more processed Data, Voice and Speech workbooks. CDRs of the same type are combined so campaigns can be benchmarked together. Select NSA or SA; Multivendor is available only when every selected CDR has already been mapped in Workspace.

NetCheck CDR Reports

NetCheck CDR Reports

Available

Use Ctrl/Cmd-click to select several CDRs of the same type. Their processed rows are concatenated using the union of their columns, preserving Campaign values for cross-campaign comparisons. Choose Slides Templates matching the selected technology; they apply only to this report and do not change the workspace default. Map Vendors from Workspace before choosing Multivendor. The common Template_CDR_analysis.pptx supplies masters and layouts for every report: the selected template creates each slide from scratch, fills its chart placeholders from the selected CDRs and keeps commentary areas blank for the analyst.
