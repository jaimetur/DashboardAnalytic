          Teams

            Team members

            A call assigned to a team with members can only be assigned to one of them; a team without members accepts every user of the workspace. A user can belong to several teams. The members are saved with Save of Statuses & Teams.

              Root Causes

              Shared by every user of this workspace. Each call can be labelled with a domain and a cause inside it. Renaming a value updates every call; a value in use cannot be removed.

                Analysis Fields

                The workspace's own follow-up fields, shared by every user. A list offers its values (each with a colour); text, long text, number, date and Yes / No fields are typed in. Fields shown in the table get a column; fields shown in the Summary get a breakdown; required fields must be filled before a call is closed. Renaming a list value updates every call; a value or field in use cannot be removed.

                The first row names the fields and the rows below list the values of each list.

                  Additional Columns

                  The additional columns of the Calls table and of its Excel export, for every user of this workspace. Analysis fields get their column in Analysis Fields. CDR columns show the value of the CDR version shown for each call: those of the table are exported too, and more can be exported to Excel only. Changing the CDR columns indexes the calls again.
