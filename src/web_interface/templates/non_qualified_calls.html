          Statuses & Teams

          Shared by every user of this workspace. The NQ Call Status of each call follows the Status Rules (the first status when no rule applies) unless it is set by hand; statuses marked Closed count as closed in the summary. Renaming a value updates every call and the Status Rules; a value in use cannot be removed.

          Statuses

            Teams

              Team members

              A call assigned to a team with members can only be assigned to one of them; a team without members accepts every user of the workspace. A user can belong to several teams. The members are saved with Save of Statuses & Teams.

                Root Cause Catalog

                Shared by every user of this workspace. Each call gets a Root Category and a Root Cause, chosen independently; the technical Domain of each one gives its colour, groups the lists (the causes of the domain of the chosen category come first) and the domain of the call. The keywords map the RCA script and NetCheck values and the comments onto the catalog. Renaming a value updates every call; a value in use cannot be removed.

                      Fields & Sections

                      The fields every call is followed up with, shared by every user of this workspace, in the order of the Excel export. Each field belongs to a section (a tab of the call) and takes its value from the analysts, the follow-up of the call, the CDR, the RCA script or keywords of the call. A list offers its values, each with a colour; text, long text, number, date and Yes / No fields are typed in. Renaming a list value updates every call and the Status Rules; a value or field in use cannot be removed.

                      Export Catalog Importing adds the new fields, values, root categories, causes, statuses and teams and takes the sections and Status Rules of the workbook; nothing is removed.

                      Sections

                        Additional Columns

                        The additional columns of the Calls table and of its Excel export, for every user of this workspace. The fields of the Analysis Center are columns of the table when chosen here or in Fields & Sections, and every field marked for Excel is exported in the catalog order. CDR columns show the value of the CDR version shown for each call: those of the table are exported too, and more can be exported to Excel only. Changing the CDR columns indexes the calls again.

                        Status Rules

                        How the NQ Call Status of every call is set from its fields. The rules are tried from top to bottom and the first one whose conditions all hold gives the status; a call that no rule matches gets the first status. A status chosen by hand stays until the call goes back to automatic. Rules follow renamed list values and statuses; a removed value leaves its conditions. Saving applies the rules to every automatic call at once.
