Vendor mapping rule
  1. For each CDR sample, split Cell_ID_A (or an equivalent Global Cell ID field) in chronological order and retain only the first and last Global Cell ID.
  2. Look up both endpoints in the selected VFUK mapping for Vodafone UK or the selected 3UK mapping for Three UK.

Vodafone UK: the same non-empty Vendor at both endpoints returns Vodafone_<Vendor>. If Ericsson is present at either endpoint and the other Vendor is different or missing, the result is Vodafone_Mixed Vendor. Every other different or missing endpoint combination returns Vodafone_Other Vendor.

3UK: the same non-empty Vendor at both endpoints returns 3_<Vendor>. Any different or missing endpoint Vendor returns 3_Mixed Vendor.

O2 and EE: no Vendor is assigned; they remain Operator comparison groups only.
